# Receiving Code Review

Treat review feedback as technical input, not an order. Before editing, understand each item and verify it against the relevant code, tests, requirements, platforms, and compatibility boundaries. Implement valid feedback; push back with concrete evidence when a suggestion is wrong or expands scope. Ask only when ambiguity materially changes the implementation. After editing, run targeted verification and respond to every review thread with the resolution or evidence.
